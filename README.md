# Love Website ❤️

A romantic interactive website made with HTML, CSS and vanilla JavaScript.

## Run
Open `index.html` in your browser.

For best results, use VS Code + Live Server.

## Personalize
Open `script.js` and edit:

- `name`
- `signature`
- `pin`
- `hint`
- `quote`

## Photos
Your uploaded photos are already placed in:

`assets/photos/`

The gallery expects:

`photo1.jpg` through `photo9.jpg`

Replace any of them with your own images if you want.

## Music
Add an MP3 named:

`assets/music.mp3`

The music button will automatically use it.

## Secret PIN
Default PIN:

`1432`

Change it inside `script.js`.
